이 단말이 맡을 작업

자동 전송을 켜면 옷 색을 고를 수 없어 기본 잉크 설정으로 나갑니다. 잘못 들어온 건도 그대로 출력됩니다.

프린터

장비를 여러 대 물릴 수 있습니다. 같은 장비에는 한 건씩 차례로 보내고, 장비끼리는 동시에 나갑니다.

직접 인쇄는 벤더 CLI 를 거치지 않아 잉크·플레이트 설정을 실을 수 없습니다. 장비 패널 설정을 따릅니다.

장비 상태

LAN 으로 연결된 장비에서만 됩니다. 조회 자체가 장비 호출이라 전송과 겹치면 장비가 바쁠 수 있습니다.

장비 설정

전송 후 작업 삭제는 pro 계열에서만 동작합니다. legacy 는 장비 패널 설정을 따릅니다. 인쇄 데이터를 남기면 무엇을 보냈는지 확인할 수 있지만 건마다 파일 세 개가 쌓입니다.
